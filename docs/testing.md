# Лабораторная работа № 4. Написание Unit тестов

Дисциплина: ИСРПО. Проект: Geometric Library.

## 1. Цели и задачи тестирования

Проверить, что библиотека вычисляет площади и периметры по формулам из [документации](README.md#math-formulas). Подобрать входные данные, вручную вычислить ожидаемые значения, автоматизировать сравнение с помощью `unittest` и зафиксировать отклонения.

## 2. Описание тестируемого продукта

Geometric Library — библиотека на Python для расчёта площади и периметра круга, квадрата, прямоугольника и треугольника. Для круга периметром считается длина окружности. Продукт предоставляет функции, сгруппированные по модулям. Их параметры и ожидаемые результаты описаны в [справочнике функций](functions.md).

## 3. Область тестирования

Проверяются восемь документированных функций. Для каждой фигуры написан отдельный класс тестов.

| Модуль | Функции | Класс тестов |
| --- | --- | --- |
| `circle.py` | `area(r)`, `perimeter(r)` | `CircleTestCase` |
| `square.py` | `area(a)`, `perimeter(a)` | `SquareTestCase` |
| `rectangle.py` | `area(a, b)`, `perimeter(a, b)` | `RectangleTestCase` |
| `triangle.py` | `area(a, h)`, `perimeter(a, b, c)` | `TriangleTestCase` |

Производительность, безопасность и обработка некорректных аргументов вне области проверки. Нулевые значения проверяются как граничные значения формул.

## 4. Стратегия тестирования

Используется функциональное модульное тестирование. Каждый метод `test_...` вызывает одну функцию из библиотеки. Ожидаемые значения рассчитаны заранее по формулам. Например, для прямоугольника со сторонами 5 и 10 ожидаемая площадь равна 5 × 10 = 50, а периметр равен 2 × (5 + 10) = 30.

| Функция | Входные данные и ожидаемые результаты |
| --- | --- |
| `circle.area` | `(3)` → ≈ 28.274333882308, `(0)` → 0, `(0.5)` → ≈ 0.785398163397 |
| `circle.perimeter` | `(3)` → ≈ 18.849555921539, `(0)` → 0, `(0.5)` → ≈ 3.141592653590 |
| `square.area` | `(5)` → 25, `(0)` → 0, `(2.5)` → 6.25 |
| `square.perimeter` | `(5)` → 20, `(0)` → 0, `(2.5)` → 10 |
| `rectangle.area` | `(5, 10)` → 50, `(10, 0)` → 0, `(10, 10)` → 100 |
| `rectangle.perimeter` | `(5, 10)` → 30, `(10, 0)` → 20, `(2.5, 3.5)` → 12 |
| `triangle.area` | `(6, 4)` → 12, `(6, 0)` → 0, `(2.5, 3)` → 3.75 |
| `triangle.perimeter` | `(3, 4, 5)` → 12, `(5, 5, 5)` → 15, `(2.5, 3.25, 4)` → 9.75 |

Все классы в [файле тестов](../test_geometry.py) наследуются от `unittest.TestCase`. Для точных значений используется `assertEqual`. Для ненулевых результатов с π используется `assertAlmostEqual` с округлением разности до девяти знаков после запятой.

Команда запуска из корня репозитория:

```bash
python3 -B -m unittest discover -v
```

Параметр `-v` выводит результат каждого теста. Параметр `-B` отключает запись файлов кэша Python.

## 5. Критерии приёмки

- Все 24 теста обнаруживаются и запускаются.
- Все восемь документированных функций доступны. На выбранных входах функции возвращают ожидаемые значения, а тесты завершаются без ошибок.
- Результаты запуска и обнаруженные дефекты отражены в отчёте.

## 6. Ожидаемые результаты

Если библиотека соответствует документации, все 24 теста получат статус `ok`, а итоговый статус запуска будет `OK`. При отклонении в отчёте указываются функция, входные данные, ожидаемое и фактическое поведение.

## 7. Актуальные результаты тестирования

Запуск выполнен на macOS с Python 3.14.0.

| Фигура | Всего | Прошли | Ошибки выполнения |
| --- | ---: | ---: | ---: |
| Круг | 6 | 6 | 0 |
| Квадрат | 6 | 6 | 0 |
| Прямоугольник | 6 | 3 | 3 |
| Треугольник | 6 | 6 | 0 |
| **Итого** | **24** | **21** | **3** |

Фрагмент вывода:

```text
AttributeError: module 'rectangle' has no attribute 'area'
Ran 24 tests in 0.001s
FAILED (errors=3)
```

Все три ошибки относятся к одному дефекту. Для вызовов `rectangle.area(5, 10)`, `rectangle.area(10, 0)` и `rectangle.area(10, 10)` ожидались числа 50, 0 и 100 соответственно. Python выдаёт `AttributeError`, потому что функция отсутствует. Сравнение с ожидаемым числом во всех трёх случаях не выполняется.

## 8. Выводы из результатов тестирования

Семь функций прошли проверки на выбранных данных. Критерий приёмки библиотеки не выполнен из-за отсутствия `rectangle.area`. Исходные файлы фигур в этой лабораторной не менялись. После восстановления функции следует повторно запустить весь набор тестов.
